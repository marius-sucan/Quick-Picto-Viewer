# Useless globals — audit of the top-level `Global` blocks

**Scope:** the four column-0 `Global` declaration blocks in `quick-picto-viewer.ahk`
(lines 98–207, 209–259, 261–395, 525) = **1164 declared globals**.
Every occurrence in `quick-picto-viewer.ahk` + `lib\*.ahk` was classified as
**write** (assignment / `++` / `--` / compound-assign), **read** (any other use of the
value), or **plumbing** (the name passed as a *string* to `RegAction` / `INIaction` /
`GuiAdd*`, a `v`/`g`/`hwnd` control binding, a `GuiControl[Get]` target).
Comments and comment-only lines excluded.

Read-count distribution: 0 reads → 11 · 1 read → 104 · 2 → 78 · 3 → 87 · 4 → 93 · 5 → 80 · 6+ → 711.

**Read this before deleting anything:** 12 globals look dead to a plain grep but are
reached through *dynamic* names and must be left alone —
`QuickFileActAfter1..6` / `QuickFileActFolder1..6` are consumed as
`QuickFileActFolder%thisVar%` (line 46279) and `QuickFileActAfter%thisVar%` (46338),
and registered as `"QuickFileActAfter" A_Index` (46358). The 20 below were checked
against that pattern; none of them has a dynamic-name prefix anywhere in the code.

### 1. `mustGenerateStaticFolders` — 10 writes, **0 reads**

## Tier 2 — present, persisted, but structurally broken

### 4. `initialCustomShapeCoords` — 1 write, 1 read, **6 plumbing sites**
Written with **two** fields, read expecting **four**, so the read is always blank:
```
80667  convertEditorCustomShape2viewerCoords
         initialCustomShapeCoords := imgSelX1 "|" imgSelY1   ; i forgot what this is for ^_^
15574  generateAlphaMaskBitmap
         tempArray := StrSplit(initialCustomShapeCoords, "|")
15576    tRimgW := (tempArray[3]>1) ? Round(rW*fAgScal) : Round(rImgW*fAgScal)
15577    tRimgH := (tempArray[4]>1) ? Round(rH*fAgScal) : Round(rImgH*fAgScal)
```
`tempArray[3]` / `[4]` are never populated, so both ternaries always take the
`else` branch — the alpha-mask gradient scale silently ignores this. On top of
that it is round-tripped to the INI from 6 places (47592, 48153, 48169, 48214,
48265, 80668). Either write 4 fields or delete the global and both branches.
The author's own comment on line 80667 says the rest.

### 5. `InternalFilterString` — 0 writes, 0 reads, 2 plumbing sites
Not a variable at all: it is only the name of a write-only Edit control used to
show an error string.
```
32948  GuiAddEdit("... vInternalFilterString", filesFilter, ...)
33172  GuiControl, SettingsGUIA:, InternalFilterString, % (regexBad=1) ? "Invalid regular expression provided." : newFilter
```
The value is never read back. The entry in the declaration block buys nothing.

## Tier 4 — single-write / single-read couriers
Each of these exists only to hand one value from one function to exactly one other.
A parameter, a return value, or `Func().Bind()` removes each of them.

### 11–12. `delayiedHUDmsg`, `delayiedHUDperc`
```
65124-65125  showDelayedTooltip       delayiedHUDmsg := msg ; delayiedHUDperc := perc
65117        dummyDelayShowToolTip    showTOOLtip(delayiedHUDmsg, 0, 0, delayiedHUDperc)
```
The whole point of `dummyDelayShowToolTip` is to carry these two values across a
`SetTimer`. `SetTimer, % Func("showTOOLtip").Bind(msg,0,0,perc), -N` deletes the
function *and* both globals.

### 13–14. `hudBTNwidthFuncu`, `hudBTNheightFuncu`
```
97223-97224  CreateOSDinfoLine   hudBTNheightFuncu := imgH + posYu ; hudBTNwidthFuncu := imgW + posXu
10138        WinClickAction      If (IsFunc(hudBTNfuncu) && hudBTNfuncu && hudBTNheightFuncu && mY<hudBTNheightFuncu && mX<hudBTNwidthFuncu && hudBTNtypeFuncu=1)
```

Two of the four `hudBTN*` globals; one hit-test rectangle spread over four

### 15. `prevSelDotX` / `prevSelDotY` / `prevSelDotAx` / `prevSelDotAy` — 4 globals, 1 write site, 1 read site

## Suggested order of work
1. Delete `mustGenerateStaticFolders`, `wasVPfxBefore` and their 14 assignments — zero behaviour change.
2. Delete `CountFilesFolderzList` and fix or drop the broken `GuiControlGet` at 94743.
3. Decide on `initialCustomShapeCoords`: write 4 fields, or remove it and the two dead ternaries at 15576–15577 plus the 6 INI round-trips.
4. Demote Tier 3 to `static` / locals (mechanical, contained).
5. Collapse Tier 4 couriers as you touch those code paths — `delayiedHUD*` and the four `hudBTN*` are the two that pay off most.
