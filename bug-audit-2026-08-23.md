# QPV bug audit — 2026-08-23

Whole-codebase audit run 2026-08-23 on master @5e55bfe (AHK sources + `QPV DLL source code/`).
Reported to the user; **not fixed at the time of writing** — verify before re-reporting. The
three leftovers of the 2026-08-06 audit (autoSelectDupesInGroups, SQLdeleteEntriesMarked,
highlightActiveCtrl) were confirmed FIXED in the meantime; the `zoomBlurBitmap()` pass-through
fix that audit recorded as done is NOT in the repo's `qpv-main.cpp` (in-place `blurWeighByAlpha`
+ "untouched" reads still there, same in `rotateBlurBitmap()`).

Confirmed, most severe first (line numbers as of 5e55bfe):
1. `updateUIFiltersPanel()` :33093 — date filters (Modified/Created date) are gated on
   `min(FilteruMinRange, FilteruMaxRange)!=""`, the DISABLED numeric min/max edits, which have no
   default -> "No filter has been defined" in a fresh session.
2. `SaveClipboardImage()` :59107 — unmodified multi-frame file at page/frame >0 saved "AS" with a
   different extension: `dilemma := ""` but `msgResult` keeps the dilemma text -> `Else Return`,
   silent abort.
3. `askAboutFileSave()` :63506 — x64 `lvls=2` but one edit == `undoLevelsRecorded=2`, so a single
   edit is discarded without the save prompt (PgDn, Escape, J...). Left/Right are blocked after
   one edit (okayu `<2`), which is the tell that the threshold is off by one.
4. `VPchangeSelRotation()` :12125 — `+ stepu` lost in v6.1.75 (f6b7c06); Shift+0/Shift+9 and the
   "Rotate selection +/-1°" menu items do nothing.
5. `switchIndexEntries()` :41602 — swaps DB `imgidu` using list POSITIONS instead of
   `resultedFilesList[i,12]`; wrong rows on sorted / gapped SLDBs.
6. `SetImageAsAlphaMask()` :4168-4179 — restore swaps VPselRotation <-> EllipseSelectMode.
7. `changeImgRotationInVP()` :12211 — `clampInRange(x, 0, 360 - stepu, 1)` with negative stepu
   -> 365°/361° when decreasing from 0 (v6.1.75 regression).
8. processDefaultKbdCombos :1291-1302 — Alt+[ / Alt+] gamma inverted vs menu/help/changelog.
   (help-keyboard-shortcuts.txt itself has the brush-bracket rows and the Ctrl+-/Ctrl+= OSD rows
   inverted vs code+menus — doc bug.)
9. `UIfindDupesCheckboxes()` :89677 — `GuiControl, SettingsGUIA:, userFindDupesFilterHamDist, %v%`
   on a DropDownList APPENDS "1"/"0" items every time "Select all" is clicked in Custom mode.
10. `PanelRenameThisFile()` :43518 — `ToggleImgFavourites(newPath, "rem")` after the rename; the
    old path stays in the faves file as a dead entry, the renamed image loses its flag.
11. `uiPopulateCachesOverview()` :36143 — the 08-21 static cache is never invalidated by
    delete / remove entry / add folder / cleanDeadFilesList / pool image-props writes.
12. `PanelFindDupes(3)` from the stats panel never opens on "Collect data" (CurrentPanelTab dead;
    Tab3 uses thisPanelTab).

Minor/cosmetic also reported: leet-speak V/W collapse in `applyTextTransform()`; empty criteria in
the "No indexed file matched" tooltip; RegEx filter mode silently LIKE on SLDB; Q in B/W-dithered
mode sets imgFxMode=1 without repaint; E selects sub-folder files too; PanelSaveImg disables a
checkbox before creating it; `wasErrorC` never assigned in SaveFilesList; `showQuickActionButtonsDrawingShape()`
passes "Forced" where `CreateTempGuiButton()` tests `killWin!="force"` (touch-only, maybe intended).

(`x := [a,b,c]` then `b := x[1]`); `GuiControl, <gui>:, <DropDownList var>, value` (blank
sub-command appends to list controls); `git log -L` on "lost `+= step`" lines from v6.1.75
(f6b7c06 rewrote eight inc/dec helpers, one regressed); help-shortcuts table vs
processDefaultKbdCombos direction (inc/dec) cross-check. The "rare identifier within edit
distance 1 of a common one" typo scan was noise. kMenu Add/Check labels, SetTimer/Func/g-label
targets and keyboard func2Call names were all clean again — skip next time.
